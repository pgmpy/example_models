This is a collection of example causal models from various sources. This repo acts as data storage for these example models and is used by pgmpy's model loader for fetching data. The following is the list of sources (and references) where these models have been collected. Please cite the appropriate package if you use any of these models in your research.

1. [bnlearn repository](https://www.bnlearn.com/bnrepository/): Collection of discrete, continuous, and hybrid Bayesian Networks.  
      **License:** CC BY-SA 3.0  
      **Reference:** Scutari M (2010). "Learning Bayesian Networks with the bnlearn R Package." Journal of Statistical Software, 35(3), 1–22. doi:10.18637/jss.v035.i03.  
2. [DAGitty](https://www.dagitty.net/): Collection of DAGs from academic literature.  
     **License:** GNU General Public License v2.0  
     **Reference:** Textor, Johannes, Juliane Hardt, and Sven Knüppel. "DAGitty: a graphical tool for analyzing causal diagrams." Epidemiology 22.5 (2011): 745.
